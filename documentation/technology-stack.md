# Technology Stack & Tooling Rationale

| Layer | Technology | Version | Rationale & Selection Criteria |
| :--- | :--- | :--- | :--- |
| **Frontend Framework** | **Next.js (App Router)** | `15.1.7` | High-performance React 19 server components, static pre-rendering, and seamless edge/serverless API integration. |
| **Language** | **TypeScript** | `5.7` | Strict static typing for financial accounting contracts, API responses, and evidence schemas. |
| **Styling & Design** | **Tailwind CSS** | `3.4` | Enterprise fintech palette (Navy `#0F2747`, Cool Gray `#F5F7FA`, White cards, semantic risk colors). |
| **Icons & Visuals** | **Lucide React** | `0.475` | Crisp fintech and enterprise analytics icons. |
| **Charts** | **Recharts** | `2.15` | Declarative SVG financial trend charts (Area, Bar, Line) with custom financial tooltips and responsive wrappers. |
| **ETL & Analytics** | **Python (Pandas, NumPy)** | `3.13` | High-speed tabular manipulation, cleaning pipelines, and statistical profiling across 137,984+ records. |
| **Relational Database**| **PostgreSQL** | `15+` | Dimensional star-schema, B-Tree indexes, and advanced window functions (`DENSE_RANK`, `LAG`, `LEAD`). |
| **AI Intelligence** | **Google Gemini API** | `gemini-2.5-flash` | Ultra-low-latency, boardroom-grade financial reasoning strictly guided by server-side evidence bundles. |
| **Document Reporting**| **ReportLab** | `5.0` | Server-side programmatic PDF generation with professional typography, scorecards, and data tables. |
| **Business Intelligence**| **Microsoft Power BI**| Desktop / Service | Enterprise BI modeling with DAX measures across 8 analytical report pages. |
| **Deployment** | **Vercel** | Edge / Serverless | Production hosting with environment variable encryption and zero downtime. |
